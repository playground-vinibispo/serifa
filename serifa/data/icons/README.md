# Application icon

The paper composition is part of Serifa and is licensed under GPL-3.0-only.
The S outline was rendered from LaTeX `\mathscr{S}` using Ralph Smith’s
Formal Script (RSFS), with the Type 1 conversion by Taco Hoekwater.
No font files are bundled or required at runtime.

The RSFS distribution permits use and distribution, asking that modified
font files be renamed and the original author credited. The Type 1 conversion
adds no restrictions. This icon contains a rendered glyph, not a modified font.
